=== WPP Lab Chat do Site ===
Requires at least: 5.8
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.2.0
License: Proprietary

Chat ao vivo no site conectado ao painel de atendimento WPP Lab.

== Instalação ==
1. Plugins > Adicionar novo > Enviar plugin > selecione o .zip baixado do painel.
2. Ative o plugin. A URL do painel, a chave e o segredo já vêm preenchidos.
3. Ajuste cores e textos em Configurações > Chat do Site.
